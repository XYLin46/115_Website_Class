WEEK 07

RWD 響應式設計與 CSS 動畫

以 mobile-first 建立流動版面，再用 transition、transform 與 keyframes 加入適量回饋。

開啟完整示範下載投影片

本週目標

Mobile first

預設先服務小螢幕，再逐步增加欄數。

Media query

在內容開始擁擠前設定 breakpoint。

動態回饋

優先動畫 transform 與 opacity。

關鍵程式

.hero { display: grid; gap: 32px; }
@media (min-width: 760px) {
  .hero { grid-template-columns: 1.4fr .8fr; }
}
.button { transition: transform .25s; }
.button:hover { transform: translateY(-4px); }

動畫不能成為取得資訊的唯一方式，並應尊重 prefers-reduced-motion。

作業

繳交 390px 與 1280px 畫面截圖，並加入一個 hover 與一個 keyframes 動畫。

測試

  • 無水平捲軸
  • 手機為單欄
  • 桌面為雙欄
  • 文字大小可讀
