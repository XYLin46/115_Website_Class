# Week07 RWD 響應式設計與 CSS 動畫

課程網頁：[開啟 Week07 練習頁](https://xylin46.github.io/115_Website_Class/Week07/)

## 練習內容

- 設定 viewport
- 使用 mobile-first 規劃小螢幕版面
- 使用 media query 建立內容導向的斷點
- 使用 `transition` 與 `transform` 製作 hover 回饋
- 使用 `@keyframes` 與 `prefers-reduced-motion`

本週會測試 390px 手機版與 1280px 桌面版，確認頁面沒有水平溢出。
