# GitHub 入門

課程網頁：[建立 GitHub 帳號與第一個專案](https://xylin46.github.io/115_Website_Class/GitHubStart/)

## 練習內容

- 申請 GitHub 帳號並完成 Email 驗證
- 認識 repository、README 與 commit
- 建立第一個公開 repository
- 直接從 GitHub 網頁建立 `index.html`
- 使用 `main` 分支與根目錄啟用 GitHub Pages
- 取得並繳交自己的 `github.io` 網址

帳號密碼、Email 驗證碼與兩階段驗證碼只能由本人輸入，不要分享給其他人或 AI 工具。
