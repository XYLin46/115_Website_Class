BEFORE WEEK 03

建立 GitHub 帳號與第一個專案

不使用指令，直接從 GitHub 網頁完成帳號、repository、第一個 HTML 檔案與公開網站。

開始設定前往 GitHub 註冊

一 建立 GitHub 帳號

  1. 前往 github.com/signup。
  2. 輸入可正常收信的 Email。
  3. 設定密碼與 GitHub 使用者名稱。
  4. 依畫面完成驗證，並到信箱確認 Email。
  5. 登入後記下自己的使用者名稱，未來網址會使用它。

帳號安全：密碼、Email 驗證碼與兩階段驗證碼只能由本人輸入，不要提供給老師、同學或 AI 工具。

準備資料

  • 可收信的 Email
  • 未被使用的帳號名稱
  • 自己記得住的安全密碼

完成標準

能登入 GitHub，右上角可以看到自己的頭像與帳號選單。

二 建立第一個 repository

Repository 可以理解成一個存放專案檔案、版本紀錄與說明文件的線上資料夾。

STEP 1

開啟新增頁面

登入後按右上角加號，選擇 New repository；也可以直接前往 github.com/new。

STEP 2

填寫專案資料

Repository name 輸入 my-first-website，Description 可填寫「我的第一個網頁」。

STEP 3

選擇公開範圍

選擇 Public，開啟 Add a README file，最後按 Create repository。

Repository 名稱建議只使用英文字母、數字、連字號與底線，不要使用空格或中文。

三 建立第一個網頁檔案

  1. 進入剛建立的 repository。
  2. 選擇 Add file，再選擇 Create new file。
  3. 檔名輸入 index.html。
  4. 貼上以下 HTML，將姓名改成自己的名字。
  5. 按 Commit changes，確認後再次提交。
<!doctype html>
<html lang="zh-Hant">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>我的第一個網站</title>
</head>
<body>
  <h1>你好，我是王小明</h1>
  <p>這是我的第一個 GitHub 專案。</p>
</body>
</html>

什麼是 commit

Commit 是一次有說明文字的版本紀錄。每次修改後提交，就能保留變更歷史。

檔名注意

入口檔案必須命名為小寫的 index.html，不要寫成 index.htm.txt。

四 使用 GitHub Pages 發布

  1. 進入 repository 的 Settings。
  2. 在左側選單找到 Pages。
  3. Source 選擇 Deploy from a branch。
  4. Branch 選擇 main，資料夾選擇 / (root)。
  5. 按 Save，等待 GitHub 建置網站。

完成後，網址通常是：

https://你的帳號.github.io/my-first-website/

第一次發布或更新後可能需要等待幾分鐘。回到 Settings → Pages，可以查看網站網址與部署狀態。

完成檢查

  • Repository 為 Public
  • 根目錄有 index.html
  • 分支為 main
  • 發布資料夾為 root
  • 網址可正常開啟

網址規則

英文字母大小寫與資料夾名稱必須完全一致。

課堂練習

練習一

完成 GitHub 帳號註冊與 Email 驗證。

練習二

建立公開的 my-first-website repository 與 README。

練習三

建立 index.html，發布 GitHub Pages，繳交公開網址。
