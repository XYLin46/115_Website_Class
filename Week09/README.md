# Week09 期中上機考

考試網頁：[開啟 Week09 期中考頁](https://xylin46.github.io/115_Website_Class/Week09/)

## 考試內容

- 60 分鐘完成活動報名網頁
- 基本版型包含 HTML 結構、語意標籤、表單、基本 CSS 與百分比寬度
- 四個加值項目為盒模型、Flexbox、RWD 與 hover、JavaScript 報名訊息
- 可查詢前八週作品，也不特別禁止使用 AI
- 必須能說明自己的程式碼，並完成教師指定的小幅修改

`starter` 資料夾提供考試使用的 HTML、CSS 與 JavaScript 起始檔。
