WEEK 06

現代網頁排版魔法 Flexbox

讓父元素決定方向、對齊、間距與換行，建立導覽列、Hero 與彈性卡片。

開啟完整示範下載投影片

本週目標

容器與項目

辨認 flex container 與直接子元素。

兩條軸線

用 justify-content 與 align-items 對齊。

彈性尺寸

grow、shrink、basis、wrap 與 gap。

關鍵程式

.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 22px;
}
.card { flex: 1 1 250px; }

課堂任務

  1. 建立品牌與連結左右分組的導覽列。
  2. 建立文字與視覺並排的 Hero。
  3. 讓三張活動卡片自動伸縮與換行。

作業

完成 Flexbox 活動首頁，並新增第四張卡片測試換行。

提醒

Flexbox 的排列屬性大多寫在父元素，不要用大量 margin 硬推位置。
