doctype、html、head、body 與常用文字標籤。

語意化標籤

header、nav、main、section、article、footer。

HTML5 表單

label、input、select、textarea 與基本驗證。

課堂任務

  1. 建立一頁活動介紹。
  2. 將一般 div 改成適合的語意標籤。
  3. 加入姓名、Email、票種與人數欄位。
  4. 確認 label 與 input 正確配對。

完成檢查

  • 標題層級合理
  • label 可點擊
  • 必填欄位有效
  • 不使用 CSS
