# Week05 CSS3 盒模型與定位

課程網頁：[開啟 Week05 練習頁](https://xylin46.github.io/115_Website_Class/Week05/)

## 練習內容

- 理解 content、padding、border、margin
- 使用 `box-sizing: border-box`
- 練習 `max-width`、`min-height` 與 `overflow`
- 使用 relative 與 absolute 製作角落標籤
- 使用 sticky 導覽列與 fixed 回頂端按鈕

本週重點是能預測元素實際尺寸，並找出定位時所參考的父元素。
